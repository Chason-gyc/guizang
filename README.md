# 归藏

万象归藏，智慧自生。

归藏是一个为个人创作与 AI 产品实践服务的本地 AI 原生知识系统。它将外部资料、个人想法和实践经验持续编译成带有个人判断的知识，并进一步转化为选题与创作成果。

项目当前处于设计阶段，尚未开始编码。

## 当前目标

第一版验证以下完整闭环：

```text
输入链接或想法
→ 形成带立场的单源笔记
→ 更新已有主题知识
→ 生成可执行选题
```

实际使用方式和验证命令将在首个可运行版本完成后补充。
